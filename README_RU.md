Adnify объединяет редактирование кода, выполнение задач с ИИ, генерацию ресурсов и проверку в браузере в настольной среде разработки. Используйте Agent Mode для непосредственной реализации или Plan Mode для проверки требований и зависимостей перед запуском.

> Эта русская версия содержит обзор продукта и руководство по началу работы. Подробности функций, архитектуру и список участников и спонсоров см. в [английской](README.md) или [китайской](README_CN.md) версии. Перевод README не означает поддержку этого языка в интерфейсе приложения.

![Демонстрация Adnify](images/main.gif)

## Основные возможности

- **Agent Mode**: задавайте вопросы, изучайте код, редактируйте файлы, выполняйте команды и проверяйте результаты в одной задаче. Разрешения, просмотр различий и контрольные точки помогают проверять изменения.
- **Plan Mode**: проверка требований → проверка плана → центр выполнения → проверка результатов. Поддерживаются зависимости, выбор модели для каждой задачи, параллельное выполнение и отдельные рабочие диалоги.
- **Редактор кода**: Monaco Editor, LSP для разных языков, ИИ-дополнение, встроенное редактирование, отладчик и интеграция с Git.
- **Генерация ресурсов**: подключайте HTTP JSON API для изображений, видео, аудио и файлов; создавайте ресурсы в ходе задачи и используйте их повторно из библиотеки.
- **Проверка в браузере**: взаимодействуйте со страницами, изучайте DOM, стили, консоль и сеть, делайте снимки экрана и проверяйте отображение на телефонах и планшетах.
- **Управление выполнением**: управляйте командами и фоновыми сервисами из разных окон, журналами, очередями и ограничениями ресурсов.
- **Уведомления и расширения**: системные уведомления, вебхуки, Skills, MCP и память проекта.
- **Темы**: Adnify Dark, Midnight, Cyberpunk и Dawn.

## Быстрый старт

Требуются Node.js **24.x начиная с 24.19.0** (`^24.19.0`), pnpm **11.22.0** и Git. Node 22 и версии 25 и выше не входят в поддерживаемый диапазон. Python нужен только для сборки нативных модулей из исходников.

```bash
git clone https://github.com/ad-naan/adnify.git
cd adnify
```

После клонирования репозитория выберите закреплённую версию Node с помощью `nvm use`, `fnm use` или `mise install`. Затем выполните:

```bash
corepack enable
pnpm install
pnpm dev
```

Команда `pnpm dist` создаёт установочные пакеты в `release/`. Если Electron сообщает `failed to install correctly`, удалите `node_modules/electron` и повторите `pnpm install` с поддерживаемой версией Node.

## Настройка моделей ИИ

1. Откройте настройки сочетанием `Ctrl+,` и выберите вкладку Provider.
2. Выберите провайдера и введите необходимый ключ API.
3. Выберите модель и сохраните настройки.

Поддерживаются OpenAI, Anthropic, Google, DeepSeek, Ollama и OpenAI-совместимые API. Используйте `@`, чтобы добавить файлы или `@codebase`, `@git`, `@terminal`, `@symbols` и `@web` в контекст. Выделите код и нажмите `Ctrl+K`, чтобы запросить редактирование прямо в редакторе.

## Работа с Plan Mode

1. Опишите цель и подтвердите требования и критерии приёмки.
2. Проверьте зависимости, ожидаемые результаты, параллельность, роли и модели.
3. Одобрите план и следите за ходом работы и запросами разрешений в TaskBoard. При необходимости приостанавливайте и возобновляйте выполнение.
4. Проверьте результат и примите его либо запросите изменения.

## Архитектура и технологии

Проект использует Electron, React, TypeScript и Vite. `src/renderer` содержит интерфейс и выполнение Agent, `src/main` — привилегированные функции и сервисы, `src/shared` — общие типы и настройки. Индексирование, хранение сессий и ресурсов и обработка содержимого выполняются в изолированных сервисных процессах.
