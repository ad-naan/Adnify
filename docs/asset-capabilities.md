# 自定义素材能力：第一阶段使用说明

入口：**设置 → 扩展 → 素材能力**。应用没有内置厂商、模型或生成服务，不要求 MCP。当前实现使用用户自定义 HTTP JSON API。

## 创建工具

1. 点击“添加工具”，在弹窗中粘贴服务文档或调用代码。代码中的响应类型、结果读取方式也可用于识别输出，不强制提供另一份 JSON；异步服务还需提供查询任务和完成结果的读取方式。
2. 点击“生成配置草稿”。使用当前配置的对话模型，示例会发送给该模型；请先将真实密钥替换为 `YOUR_API_KEY`（程序也会遮盖常见鉴权字段）。缺少信息时 AI 会提示补充。生成结果通过本地格式校验，但不会保存或调用素材接口。
3. 如需认证，配置 `auth`，在独立密钥输入框填值；密钥经系统安全存储能力加密后持久化，导出配置不包含密钥。不同能力各自管理凭据。
4. 检查名称、用途、请求地址、生成类型和请求超时，再点击“保存工具”。详细映射及导出放在“高级配置（JSON）”中；添加弹窗也支持手动配置与导入。成功生成后的 AI 说明默认收起，缺失信息则留在示例弹窗内提示。当前页的保存独立于设置弹窗底部的其他设置保存。
5. 保存后，下一轮 Agent 会加载 `asset__<id>__r<revision>`。每次配置变更产生新修订，旧调用不会静默采用新 schema。

工具列表每行提供配置、启用开关和独立“试运行”弹窗，主页不展开编辑器或测试表单。“参考素材与最近任务”默认收起，试运行提交后自动展开。

`request.timeoutSeconds` 支持 1–600 秒，未设置时为 60 秒。AI 会保留示例中的明确超时，例如 `AbortSignal.timeout(180_000)` 转成 180 秒；不会照搬不确定网络失败后的自动重试，以免重复生成。图片真实 MIME 由返回字节识别，无需依赖 Base64 字段名判断格式。

可参考 [图片生成 JSON 样例](examples/image-service-config.json) 填写配置结构。请求地址留空，模型使用占位值；使用前需按自己的接口填写，认证值单独设置。此文件不自动注册为工具。

配置编辑器和以下 JSON 均为结构样例，不包含 URL 地址。使用前需填写自己的请求地址；异步任务还需填写包含 `{job_id}` 的同源查询地址。

```json
{
  "id": "my_poster",
  "revision": 1,
  "name": "产品海报",
  "description": "根据画面描述生成产品海报图片。",
  "enabled": true,
  "kind": "image",
  "inputSchema": {
    "type": "object",
    "properties": {
      "prompt": {"type": "string", "description": "画面描述"},
      "ratio": {"type": "string", "enum": ["1:1", "16:9"], "default": "1:1"}
    },
    "required": ["prompt"],
    "additionalProperties": false
  },
  "request": {
    "url": "",
    "body": {
      "description": {"$input": "/prompt"},
      "aspect_ratio": {"$input": "/ratio"},
      "model": "your-model-id"
    }
  },
  "auth": {"header": "Authorization", "prefix": "Bearer "},
  "output": {
    "itemsPath": "/images",
    "urlPath": "/url",
    "mimeType": "image/png",
    "allowedOrigins": [],
    "maxFileMB": 20
  }
}
```

`model` 是普通请求字段，按自己的接口修改或删除；核心不认识任何模型 ID。

## 映射规则

- 输入支持 string、number、integer、boolean、object、array；可定义字符串枚举、数字范围、必填字段、默认值和最多六层嵌套。未声明的输入会被拒绝。
- `{"$input":"/prompt"}` 引用输入值，保留字符串/数字/对象类型；其他值按原样传递，不执行字符串表达式或脚本。
- 路径使用 JSON Pointer。`/images` 选择顶层 images；空字符串选择当前对象本身；`/0` 访问数组第一项。
- `output.itemsPath` 选择单个结果或结果数组；每次接收 1–16 个文件。
- 每项结果用 `urlPath` 或 `base64Path` 提取，二者只能选一个。若 images 数组直接包含下载地址字符串，则 `urlPath` 设为 `""`。
- URL 下载默认仅允许提交接口同源地址；其他域名需在 `allowedOrigins` 中列出准确 origin（协议、主机及可选端口），不包含路径或尾部斜杠。
- 当前不跟随 HTTP 重定向，不携带提交接口的密钥到文件下载地址；使用可直接下载的结果 URL。
- 同步和查询响应上限为 32 MB。较大的文件优先通过 URL 返回；不要将视频以 Base64 放在 JSON 响应中。

## 异步服务

提交使用 POST JSON，轮询使用同源 GET。为配置增加：

```json
{
  "async": {
    "jobIdPath": "/id",
    "statusUrl": "",
    "statusPath": "/status",
    "successValues": ["completed"],
    "failureValues": ["failed"],
    "pollSeconds": 5
  }
}
```

`{job_id}` 由运行时编码替换。完成响应继续使用同一套 output 映射；当前要求完成状态与结果文件在查询响应中一起返回。单独结果 endpoint、multipart 上传、流式事件与特殊签名尚未实现。

任务先持久化，再由后台提交。生成工具在同一次调用内等待最终结果，由程序内部查询状态，直到素材保存完成或失败才返回 Agent。聊天中的内嵌素材区直接展示等待状态、错误和最终结果，折叠后显示 prompt 摘要。`asset_job_wait` 不再提供给模型；`asset_job_get` 仅用于停止等待或重新打开会话后查看旧任务。

停止 Agent 会结束本地等待，但不会重复提交或取消已经在服务端运行的任务；任务和素材卡片仍可继续更新。应用重启后恢复后台任务查询，不要求打开原对话。图片、视频、音频、文件和多个结果共用素材画布，支持在卡片内切换结果、导出和查看文件；任务详情在独立窗口查看。

素材区无边框、无阴影、无可见工具标题，只用主题浅色差区分。操作在悬停或键盘聚焦时出现。折叠后采用与其他工具一致的紧凑行，显示传入的 prompt、素材图标和耗时；状态更新不会强制展开。任务摘要保留 prompt 供重启后显示，但不暴露其余输入参数。

提交中断但不确定远端是否收到时，标记 `submission_unknown`，需要核对服务记录，不会自动再提交。下载失败可单独重试。只能取消尚未向远端提交的排队任务，当前不承诺远端取消或退款。

## 参考图与图片编辑

在设置页“导入图片”，或让 Agent 使用 `asset_import(path)` 导入工作区图片。工具导入不读取工作区外文件；设置页文件选择器可选择其他目录。

将输入字段配置为 `{"type":"string","format":"asset-image"}`，传入已导入素材 ID。运行时读取这张图片并转成 data URI，再应用请求映射。参考图片上限 15 MB，当前支持 PNG、JPEG、WebP、GIF。

如果自己的服务支持改图，可以自行创建改图工具并将图像字段、蒙版字段映射到服务的请求结构，无须内置独立厂商逻辑。当前只支持以 data URI 方式上传图片引用。

## 存储与导出

- 默认素材库：当前应用配置目录下的 `assets/library`，设置页显示实际绝对路径。
- 可选择全局自定义目录，也可为当前项目覆盖；项目覆盖优先。
- “使用当前项目文件夹”直接取当前窗口的项目根目录，并创建 `.adnify/assets`，无需选择文件夹；“为此项目选择其他位置”才会打开目录选择器。未打开项目时不能使用项目目录。
- 修改目录只影响新任务，旧素材和在途任务保留原位置。恢复默认不会删除文件。
- 自定义目录不可用时报告错误，不静默回退到系统盘。
- 权威元数据存储在应用配置目录下 `assets/assets.sqlite`，由独立 SQLite Worker 访问；二进制文件保存在对应素材根目录。
- 用户配置统一保存在应用配置目录的 `config.json`：`assetConfiguration` 保存工具定义、参数映射和存储偏好，加入现有设置导入、导出和重置注册表；`assetCredentials` 保存系统加密后的 Cookie / 密钥，仅主进程专用接口可读写，不进入配置导出。更换机器时需要重新填写凭据。
- `assets/assets.sqlite` 只保存任务历史和素材索引。升级时自动从旧 SQLite 写入配置文件，写成功后才删除旧配置记录；迁移标记防止重置后旧配置复活。迁移不移动素材文件，不重新提交任务。
- 设置页的任务记录与参考素材分栏显示，每页 6 条，列表最大高度 360px，详情按需展开。支持删除单条记录、清空已结束任务和清空参考记录，仅作用于当前项目。删除记录保留素材文件、已有引用与任务去重标记，不会中断生成；进行中的任务不能删除。
- 生成成功自动保存素材库。结果显示在无边框的内嵌素材区，操作在悬停或聚焦时出现，折叠后显示紧凑的 prompt 行；图片可点开放大，MP4/WebM 视频与音频支持内嵌播放，视频按需读取本地文件范围以支持拖动，不将整个视频塞进 IPC。也可定位文件和导出；导出不覆盖已有文件。
- Agent 可以用 `asset_export(asset_id, destination)` 导出到项目内已存在的目录；项目外导出使用用户文件选择器。

当前尚未提供一键搬迁已有素材、每个项目的默认导出目录或素材库全文检索。不要手动搬动旧库后期待应用自动重新定位。

提交诊断区分明确的 HTTP 拒绝（如 401 / 403 / 429）、超时、网络错误、无效请求头和响应解析错误。网络或服务端结果不确定时不自动重发；已知拒绝显示为失败。旧版本已丢弃的错误原因无法事后还原。下载重试只对已经拿到结果、但保存失败的任务显示。

HTTP 错误会保留服务端错误信封中的 message/detail 等说明或简短纯文本，脱敏认证值后最多展示 1000 字符；不保存整份错误响应、调试对象、HTML 或超过 64KB 的错误正文。

## 当前边界

本阶段已实现 HTTP 配置、动态工具、图片引用、异步任务持久化、独立下载重试、图片检查与预览、自定义存储及导出。生成与 Agent 导出走现有审批；设置页试运行会提交真实请求，可能产生费用。

其他产物类型可以按配置下载为文件，3D 交互预览与专业格式检查尚未实现。视频是否能播放取决于 Electron 支持的编码，失败时仍可导出文件。MCP 到原生素材卡片的映射、代码扩展运行器、Agent 配方、工作流编辑、预算计价和自动完成后的 Agent 续跑仍是后续阶段；当前以显式查询工具衔接流程，规划阶段与隐藏子 Agent 仅可读取能力/任务状态。
