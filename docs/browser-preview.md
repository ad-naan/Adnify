# 浏览器预览

预览工具栏提供桌面、手机（390 × 844，3 倍像素密度）和平板（820 × 1180，2 倍像素密度）。手机和平板可切换横竖屏，按面板大小自动缩小显示；页面得到的仍是设备的逻辑视口尺寸，CSS 媒体查询不会跟着显示缩放改变。

切换设备不重新加载页面，已输入的表单内容会保留。回到桌面恢复原来的页面缩放。设备和方向偏好会保存。模拟使用 Chromium，可检查响应式布局和触控相关特性；不能代替 Safari 或真实设备测试。未设置 viewport meta 的网站可能按移动浏览器默认的宽布局显示。

每个项目使用独立、持久的浏览器存储，同项目不同窗口共享登录态，不同项目即使使用相同 localhost 地址也相互隔离。多根工作区按预览关联的项目根目录区分。未关联项目的预览使用当前窗口的临时存储。

升级前的 `persist:adnify-preview` 是所有项目共用的存储，无法可靠判断每条登录信息属于哪个项目，因此不会自动复制到新分区。旧数据保留，新项目会话首次使用需重新登录。项目目录移动后会使用新的存储分区。

预览分区由主进程根据当前窗口的工作区生成；挂载前必须准备完成，网页不能自行指定主应用或其他项目的存储分区。设备配置仅允许操作当前窗口拥有的预览页面。

验证：`node scripts/diagnostics/preview-browser-smoke.cjs` 验证原生设备尺寸、像素密度、触控及浏览器交互；`node scripts/diagnostics/preview-environment-smoke.cjs` 使用隔离配置验证完整预览界面、缩放和跨项目存储。后者截图保存在 `.tmp/preview-environment-smoke/`。
